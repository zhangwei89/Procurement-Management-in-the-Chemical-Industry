# 第二篇 采购业务流程与全过程管理

# 第6章 采购方式选择与采购实施

---

## 章节导读

在采购全生命周期中，“采购方式的选择”是决定采购活动成败的“战略分水岭”。采用何种方式实施采办，不仅直接关乎采购效率的高低、资金利用的优劣和供应商响应的积极性，更在法律合规层面构筑了企业抵御法律纠纷、反腐败审查与内部审计风险的第一道防火墙。

然而在现实管理中，许多化工企业常常陷入两种截然相反的极端误区：一种是**“唯招标论”**，不分青红皂白、无论标的大小，哪怕买几箱办公耗材或采购独家专利配件，也机械僵化地走一套耗时数月的冗长公开招标程序，导致装置停工待料、行政成本极高而实质竞争寥寥无几；另一种则是**“唯私下谈论”**，以“工期紧急”、“工况特殊”为由，滥用单一来源与私下询价，甚至通过“化整为零”拆分工程合同的方式故意规避法定招标，最终在国家审计或反舞弊专项检查中轰然暴雷。

不同类型的化工物资与工程服务，其市场供给结构、技术成熟度与时间敏感性天差地别。采购方式的选择绝非随意的行政拍脑袋，而是一套严谨、合法、基于物资属性与市场结构的决策推演过程。本章系统解构国家招投标法定体系与企业自主采办模式的衔接机制，深入推演公开招标、邀请招标、竞争性谈判、竞争性磋商、询比价与单一来源采购的实战运行逻辑，精细拆解综合评分法与最低评标价法的防坑策略，剖析异常低价拦截、异议处理与全流程电子存证机制，为化工企业提供兼顾“效率、成本与合规”的采办实操指南。

## 6.1 采购方式法定体系与企业自主采办模式的合规适配

理解采购方式，首先必须辨析其适用的**法律场域与企业性质**。国有化工企业、混合所有制企业以及大型民营/外资化工企业，在法律适用与自由裁量权上存在重大差异。

```
┌────────────────────────────────────────────────────────────────────────┐
│                   化工采购适用的两大法律体系场域                       │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
    ┌───────────────────────────────┴───────────────────────────────┐
    ▼                                                               ▼
【第一场域：法定强制招标工程项目】              【第二场域：企业自主生产经营采办】
· 受《中华人民共和国招标投标法》及实施条例管辖  · 受《中华人民共和国民法典》合同编管辖
· 适用于大型基础设施、公用事业及国有资金投资项目· 适用于企业日常生产的原辅料、常规备品备件、
· 凡达到国家法定规模标准，【必须依法公开招标】    日常外协检修等非工程建设项目的自主采办
· 程序极其法定化，违规拆分工程构成违法犯罪      · 采购方式高度多元灵活，由企业内部制度规范定义
```

### 6.1.1 国家法定招标限额标准（必须招标的硬性红线）
根据《必须招标的工程项目规定》（国家发改委第 16 号令）及相关法规，使用国有资金投资或者国家融资的化工建设项目，其勘察、设计、施工、监理以及与工程建设有关的重要设备、材料等的采购，达到下列标准之一的，**必须进行公开招标**：
1. **施工单项合同估算价在 400 万元人民币以上**；
2. **重要设备、材料等货物的采购，单项合同估算价在 200 万元人民币以上**；
3. **勘察、设计、监理等服务的采购，单项合同估算价在 100 万元人民币以上**；
4. 同一项目中可以合并进行的勘察、设计、施工、监理以及与工程建设有关的重要设备、材料的采购，合同估算价合计达到上述规定标准的，必须招标。

### 6.1.2 企业自主采办的六大标准方式谱系
对于不属于法定必须招标范围的日常原辅材料、常规运营备件与外包服务，化工企业通常在《采购管理办法》中定义六种主流采办模式：

```
【竞争充分度由高到低 ───► 流程灵活性由低到高】
┌────────────┐    ┌────────────┐    ┌────────────┐    ┌────────────┐    ┌────────────┐    ┌────────────┐
│  公开招标  │───►│  邀请招标  │───►│ 竞争性磋商 │───►│ 竞争性谈判 │───►│  询比价    │───►│  单一来源  │
│  (Open B.) │    │ (Invite B.)│    │ (Consult.) │    │ (Negotiat.)│    │ (RFQ/Price)│    │ (Single S.)│
└────────────┘    └────────────┘    └────────────┘    └────────────┘    └────────────┘    └────────────┘
```

## 6.2 公开招标与邀请招标的标准化组织与流程合规

招标投标是化工重大资本性开支、新建扩建工程以及大宗年度原材料采购中最具公信力、竞争最为充分的采购方式。

```
┌────────────────────────────────────────────────────────────────────────┐
│                   公开招标全流程标准化关键节点时序图                   │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
       【编制招标文件与发售】 ────────► 法定发售期不少于 5 日，明确评审办法
                                    │
                                    ▼
       【澄清与修改答疑】 ────────────► 招标文件修改应在投标截止前至少 15 日发出
                                    │
                                    ▼
       【投标人编制并递交投标文件】 ──► 自招标文件发出至投标截止，法定不少于 20 日
                                    │
                                    ▼
       【开标会议】 ──────────────────► 投标截止时间公开开标，投标人数量不少于 3 家
                                    │
                                    ▼
       【评标委员会封闭评审】 ────────► 专家盲抽组建委员会，独立评分，推荐中标候选人
                                    │
                                    ▼
       【中标候选人公示】 ────────────► 法定公示期不少于 3 日，接收异议与核查
                                    │
                                    ▼
       【发出中标通知书与签订合同】 ──► 30 日内按照招标文件与投标文件订立书面合同
```

### 6.2.1 公开招标（Open Tendering）的刚性法定义务
- **广泛公告性**：必须在国家指定的官方媒介（如中国招标投标公共服务平台）发布招标公告，向全社会不特定的具备资质的潜在法人发出投标邀请；
- **充分竞争底线**：开标时，提交有效投标文件的投标人**不得少于 3 家**。少于 3 家的，依法必须重新组织招标；
- **实质性背离禁止**：中标通知书发出后 30 日内订立合同，合同的标的、价格、质量、履行期限等主要条款**严禁背离招投标文件产生实质性修改（严禁签订“阴阳合同”）**。

### 6.2.2 邀请招标（Tendering by Invitation）的法定前置条件
邀请招标直接向 3 家以上具备承担能力的特定法人发出投标邀请书。由于排除了潜在竞争者，适用条件受到法律严格限制：
1. **技术复杂或有特殊要求**：只有少数潜在投标人可供选择（如大型超临界加氢反应器制造）；
2. **涉及国家安全、国家秘密**或自然环境限制；
3. **采用公开招标方式的费用占项目总价值比例过大**（公开招标本身的招募与评审行政成本远超标的价值）。
> **审批红线**：国有资金投资项目由公开招标转为邀请招标，必须报经项目审批部门正式核准，企业无权自行决定。

## 6.3 询比价采购的适用场景、比价基准与多轮博弈

对于化工企业日常消耗的大量杠杆物资与常规物资（如常规酸碱、标准法兰管件、五金电料、水处理常规药剂），询比价（Request for Quotation, RFQ）是效率最高、应用最广的采办方式。

```
                    ┌──────────────────────────────┐
                    │      发布询价文件 (RFQ)      │
                    │ 统一工况、付款方式与交期要求 │
                    └──────────────┬───────────────┘
                                   │
                                   ▼
                    ┌──────────────────────────────┐
                    │   至少 3 家供应商背靠背报价  │
                    │ 严格密封，系统倒计时前不可见 │
                    └──────────────┬───────────────┘
                                   │
                                   ▼
                    ┌──────────────────────────────┐
                    │  第一轮开价：横向清洗与澄清  │ ───► 剔除漏项，对齐含税与运费口径
                    └──────────────┬───────────────┘
                                   │
                                   ▼
                    ┌──────────────────────────────┐
                    │  第二轮/第三轮动态比价博弈   │ ───► 设定目标线，促成阶梯式降价
                    └──────────────┬───────────────┘
                                   │
                                   ▼
                    ┌──────────────────────────────┐
                    │    满足要求之最低报价定标    │
                    └──────────────────────────────┘
```

### 6.3.1 询比价的四大核心运行规则
1. **统一规格基准（Apple-to-Apple Comparison）**：必须确保所有被询价供应商是在**完全相同的技术规格、相同的交货地点（自提 vs 送到含卸车）、相同的税率（13%增值税专票）及相同的付款账期（现汇 vs 6个月承兑汇票）**前提下报价。口径不一致的比价是毫无意义的虚假比价；
2. **多轮动态博弈机制**：在电子采购平台中，可推行“背靠背密封报价 $\rightarrow$ 采购员发起首轮商务澄清 $\rightarrow$ 供应商提交最终承诺报价”的两轮或三轮博弈流程；
3. **报价拦截线与基准线**：结合前述第 5 章测算的企业目标成本（Should-Cost）或大盘价格指数，对异常偏高的报价坚决要求其拆解成本，对异常超低报价启动倾销调查。

## 6.4 竞争性谈判与竞争性磋商在非标技术与复杂工程中的实操

当采购标的极其复杂、涉及专有前沿工艺、在动笔采购前业主无法精确拟定最终技术规格书，或者公开招标由于技术方案不确定而流标时，**竞争性谈判**与**竞争性磋商**是最具杀伤力的实战工具。

```
┌────────────────────────────────────────────────────────────────────────┐
│                   竞争性谈判 vs 竞争性磋商机制对比                     │
├──────────────┬────────────────────────────┬────────────────────────────┤
│ 比较维度     │ 竞争性谈判 (Negotiation)   │ 竞争性磋商 (Consultation)  │
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **核心逻辑** │ 先谈技术与方案，最终锁定统 │ 围绕技术方案、商务能力与价 │
│              │ 一标准后，进行**单轮报价** │ 格展开多轮沟通，**综合打分**│
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **定标原则** │ 满足实质性响应要求的       │ 综合评分第一名定标         │
│              │ **最低报价者中标**         │ (技术与商务权重权衡)       │
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **适用场景** │ 技术方案最终能够完全统一对 │ 技术极其复杂、定制化极强、 │
│              │ 齐，希望最终拼刺刀比价格   │ 无法完全同质化的前沿项目   │
│              │ (如常规装置大修外委清包工) │ (如新工艺中试装置开发总包) │
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **谈判轮次** │ 方案澄清多轮，价格最终一次 │ 方案与价格伴随磋商过程     │
│              │ 密封承诺                   │ 动态调整修改               │
└──────────────┴────────────────────────────┴────────────────────────────┘
```

### 6.4.1 竞争性谈判的实务运作四步法
1. **第一步：发出谈判文件**，明确谈判的基本目标、工艺约束与初步要求；
2. **第二步：个别分别谈判（严格保密隔离）**：谈判小组分别与每家供应商进行单独闭门沟通。**严禁在谈判中向任何一家透露其他竞争对手的技术独创方案、专利构思或报价明细**；
3. **第三步：发出最终统一技术规格说明书**：在吸收各方先进建议后，谈判小组制定出统一的最终技术要求，通知所有供应商据此修改方案；
4. **第四步：最后报价定乾坤**：所有参与供应商在规定时间内提交不可撤销的密封最终报价（Last and Final Offer, LFO），谈判小组当场解封，满足技术要求的最低报价者直接定标。

单一来源采购（Single Source Procurement）由于完全排除了市场竞争，属于腐败寻租与商业垄断的高危地带。在化工企业采购审计中，**单一来源采购项目往往是审计部门重点穿透核查的第一靶标**。

                                    │

    ▼                               ▼                               ▼

只能从特定供应商处采购，市场上  为保证原有设备的一致性或服务配套 发生突发火灾、毒气泄漏、严重停
不存在任何合法可替代的第三方    ，必须向原供应商添购，且追加金额 机风险，时间上无法满足常规采办
(如专有工艺包许可PDP、专有催化剂)占原合同金额比例受控(通常<10%)  (必须事后补齐追溯手续与说明)

## 6.6 采购招标文件与评审办法精细化设计

评标办法是引导供应商投标行为的“指挥棒”。评标办法设计不合理，不仅无法选出好供应商，反而会成为劣币驱逐良币的帮凶。

### 6.6.1 最低评标价法 vs 综合评估法

```
┌────────────────────────────────────────────────────────────────────────┐
│                   两大主流评标办法核心特性对比表                       │
├──────────────┬────────────────────────────┬────────────────────────────┤
│ 比较维度     │ 经评审的最低投标价法       │ 综合评估法 (综合评分法)    │
│              │ (Lowest Evaluated Price)   │ (Comprehensive Evaluation) │
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **核心逻辑** │ 技术标只要符合基本合格门槛 │ 技术、商务、价格、资信、售 │
│              │ ，报价最低者直接中标       │ 后各自赋分，按总得分定标   │
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **适用标的** │ 高度标准化、无技术差异通用 │ 非标设备、大型成套装置、工 │
│              │ 物资 (如工业盐、标准管件)  │ 程总包、复杂专业信息化服务 │
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **最大优势** │ 规则极其透明，杜绝寻租腐败 │ 全面权衡技术与商务，能够选 │
│              │ 空间，极大压缩采购采购成本 │ 出综合履约能力最强的服务商 │
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **潜在风险** │ 极易诱发恶意低价倾销、偷工 │ 存在人为设定主观偏向分、打 │
│              │ 减料，后期陷入停产索赔泥潭 │ 人情分的寻租风险           │
└──────────────┴────────────────────────────┴────────────────────────────┘
```

### 6.6.2 综合评分法价格分计算公式的实战陷阱与修正
在综合评分法中，价格分（通常占 30%～50% 分值）的计算模型至关重要。市面常见的公式主要有两种：

#### 1. 经典最低价基准法（线性递减模型）

$$\text{投标人价格得分} = \left( \frac{\text{评标基准价}}{\text{该投标人实际评标报价}} \right) \times \text{价格总分权重}$$

- **缺陷**：极端依赖最低报价。如果有投机者恶意报出一个接近于零的自杀式极端低价，会导致所有正常报价的优质供应商价格分被大幅拉低甚至清零。

#### 2. 复合平均基准价法（反恶意倾销推荐模型）
将所有通过技术初审的有效投标报价，剔除一个最高价和一个最低价后，计算算术平均值作为基准价：

$$\text{基准价 } P_0 = \frac{\sum_{i=2}^{N-1} P_i}{N - 2} \times K$$

其中 $K$ 为下浮系数（通常取值在 $0.95 \sim 1.00$ 之间，开标时在纪检监督下由投标人代表现场随机抽选抽取）。
- **扣分规则**：投标报价等于基准价得满分；高于基准价按比例扣分；**低于基准价一定幅度（如低于5%）同样扣分**。
- **管理效果**：彻底斩断投机者“报极端低价搅局”的动机，引导供应商理性报价并向合理成本区间靠拢。

### 6.8.2 异常低价拦截机制（Abnormally Low Bid）
根据《招标投标法实施条例》第五十一条，评标委员会发现投标人的报价明显低于其他投标报价，或者低于标底，使得其投标报价可能低于其个别成本的，**应当要求该投标人作出书面说明并提供相关证明材料**。
- **举证责任倒置**：该投标人必须在规定的合理时限内（如 2 小时），提交其原材料采购合同凭单、先进制造工时证明或独特的工艺节能专利等证明文件；
- **果断否决**：若该投标人不能合理说明或者不能提供相关证明材料证明其能够保证质量履约的，评标委员会**应当果断认定该投标人以低于成本的报价竞标，应当否决其投标**。

## 本章实战案例：某化工厂低价中标引发灾难性停工与评标机制再造

### 案例背景
华东某大型煤化工企业年产 60 万吨甲醇制烯烃（MTO）装置，核心动设备工段包含 4 台大型高压循环气往复式压缩机。该机组的核心易损耐磨消耗备件为**高频特种 PEEK/不锈钢组合式气阀（单机组配备 32 套气阀）**。该气阀长期以 120 万元/年的预算进行采购。

### 危机爆发：贪图便宜引发的“唯低价中标”噩梦
2023年春季，原有的国际知名品牌气阀供货合同期满，采购部组织对新一年度气阀采购进行公开招标。
- **致命的评标办法设计**：采购经办人员为了追求显性的降本业绩，制定了极其教条的“经评审的最低投标价法”：只要通过基本资质初审，报价最低者直接成为第一中标候选人；
- **劣币驱逐良币**：
  - 国际一线原厂及国内顶尖专业气阀厂经过精密测算，含高品质 PEEK 阀片、真空热处理与 100% 气密检验的合理报价为 **105 万～115 万元**；
  - 某新成立的民营机械加工厂 B 公司为了挤进该百亿级石化企业供应链，采取恶性自杀式低价倾销，报出了不可思议的 **42 万元超低价（降幅达 65%）**；
  - 评标委员会在“最低价中标”的死规则约束下，明知其价格不可思议，但因缺乏强制成本澄清审查制度，被迫判定 B 公司以 42 万元中标！
- **灾难降临**：
  B 公司中标后，因价格严重倒挂无法承受原厂高精材料成本，在制造中偷工减料，使用劣质回收工程塑料替代航天级 PEEK 阀片，且热处理硬度不均。
  - 新气阀换装上线满负荷运转仅 **18 天**，3 号压缩机一级排气阀的阀片在高频冲击下发生疲劳碎裂！
  - 碎裂的高硬度金属碎片随高速气流吸入压缩机气缸，导致活塞严重拉缸、气缸镜面深度划伤、活塞杆弯曲变形，触发主电机超电流联锁紧急跳车停运！
  - 事故导致整套 MTO 装置被迫紧急全线降负荷，单台机组抢修整整耗时 **8 天**；
  - 直接更换受损气缸与活塞损失 **160 万元**，全线减产经济损失高达 **1,150 万元**！
  - 采购人员为了账面省下的 70 万元，最终为企业招致了超过千万的灾难性巨亏！

### 根因复盘诊断
事故发生后，集团董事长亲自挂帅启动特巡调查，深刻复盘了本次采办机制的全面失效：
1. **采购方式选择完全教条化**：往复式压缩机气阀属于工况极度严苛的高频关键动部件，绝对不是普通法兰螺栓等通用标准件，盲目选用“最低价中标法”从根源上种下了祸根；
2. **缺乏异常低价拦截机制**：当 B 公司的报价比全行业公允成本线低出 60% 时，招标文件没有设计反恶意倾销成本澄清与举证机制，评标委员会沦为盲目看数字比大小的木偶；
3. **资质与业绩审查形同虚设**：B 公司的投标业绩合同多为普通低压小机组应用，缺乏在大规模煤化工高压连续工况下的成熟运行业绩，审查组未组织深入的现场实地飞检。

### 评标机制的全面推倒重构
该企业以此惨痛教训为戒，全面重塑了关键工业装备与核心备件的采办机制：
- **废除纯最低价法**：所有关键动静设备易损备件一律强制推行“综合评估法（双信封体系）”；
- **设置技术一票否决红线**：技术方案必须经过包含动平衡、流场仿真、材料金相检验在内的 10 项核心指标考核，技术分未达到 85 分的供应商，商务标直接封存不予开标；
- **推行“复合平均基准价法”**：价格分采用“去两极平均值下浮基准”，凡报价低于基准价 10% 以上的，不仅不加分，反而大幅扣分，并强制启动 2 小时成本穿透举证听证会；
- **重构之后的成效**：新机制实施后，该企业彻底清退了 14 家恶意低价搅局的投机作坊，重新锁定了行业前三甲高品质气阀原厂。连续运行 18 个月以来，压缩机气阀平均免维护运行寿命超过 **8,500 小时**，装置非计划停车率彻底归零。

## 本章小结与管理工具箱

### 核心认知总结
1. 采购方式的选择是合规与效率的平衡木，必须严格区分法定强制招标与企业自主采办的法律边界；
2. 坚决克服“唯招标论”与“唯随意私下谈”两个极端，基于物资卡拉杰克象限与市场结构匹配最优采办模式；
3. 谨慎使用单一来源采购，建立前置市场调研、独立专家盲审、公开平台公示的三重防火墙；
4. 评标办法是引导商业行为的指挥棒，关键设备与专业服务坚决推行综合评分法与复合基准价模型，构筑异常低价拦截机制；
5. 建立报价清单的横向清洗对齐体系，剔除缺项漏项陷阱；
6. 严格守住“禁止化整为零拆分规避招标”的法律高压红线，推进全流程电子化招采存证，确保每一笔采购经得起历史检验。

| :---: | :--- | :--- | :---: | :--- |
| 1 | **法定工程建设施工及重要设备** | 施工 $\ge 400$ 万；货物 $\ge 200$ 万 | **公开招标** | 严格法定发售与编制时限，严禁擅自转邀请招标 |
| 2 | **技术极其复杂的大型非标装置总包** | 200 万以上非标项目 | **综合评分公开招标** (双信封) | 技术占 50% 以上权重，设置技术一票否决门槛 |
| 3 | **标准化基础大宗原料与常规辅料** | 年度框架集采 (数百万至上亿) | **邀请招标 / 动态比价** | 统一质量标准与交期口径，采用公式价格联动 |
| 4 | **日常零星通用五金耗材、标准管件** | 单笔 10 万元以内零星小额 | **内网电商目录采办** | 剥离人工介入，按月合并对账，提升行政效率 |
