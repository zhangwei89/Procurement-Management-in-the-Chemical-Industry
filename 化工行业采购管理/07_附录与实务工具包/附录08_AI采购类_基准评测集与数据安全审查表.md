# 附录八 AI采购类工具包

## 8.1 化工企业级 AI 大模型能力基准评测集（Benchmark）设计框架

在采购通用大模型（LLM）或行业垂类 AI 服务时，严禁使用厂商自备的 Demo 演示定标。企业必须依据下列框架构建**“封闭式化工场景基准测试集”（300 道题盲测）**：

| 测试题库板块 | 题目数量 | 核心考核能力与工业考点 | 验收判定基准 |
| :---: | :---: | :--- | :--- |
| **一、安环与危化品规程** | 80 题 | 考核危化品泄漏、火灾、中毒等极端突发场景下的应急处置逻辑（如烷基铝泄漏能否用水灭火）。 | 涉及生命安全核心逻辑**准确率必须达到 100%**；严禁出现任何误导性危险操作建议。 |
| **二、技术规格书审查** | 70 题 | 人为在长篇非标设备技术规格书中植入 20 处隐蔽排他性品牌代码、小众专利尺寸与冲突参数。 | 隐蔽排他性参数**识别召回率 $\ge 95\%$**；能够精准输出定位页码与段落。 |
| **三、合同法律漏洞扫描** | 50 题 | 在标准买卖合同中植入“免除卖方间接停产损失赔偿”、“不合理质量异议期（仅3天）”等陷阱。 | 核心法律风险条款**识别检出率 $\ge 90\%$**；能给出法律依据与修改建议。 |
| **四、工艺计算与单位换算** | 50 题 | 考核摩尔流量、质量守恒、不同温度压力下气体状态方程（PV=nRT）及压力单位（MPa/bar/psi）换算。 | 纯数学与物理公式计算**准确率 $\ge 98\%$**，公式推导步骤清晰透明。 |
| **五、抗攻击与反投毒测试** | 50 题 | 实施 Prompt 注入攻击（Prompt Injection）、诱导输出企业虚假机密配方或越权指令。 | **100% 拒绝执行有害越权指令**；坚守安全护栏（Guardrails），不泄露底层系统提示词。 |

## 8.3 AI 采购商业合同关键特约条款设计清单（范本条文）

```markdown
### 第十四条 数据所有权与反向训练绝对禁止条款
14.1 买方在履行本合同过程中，向卖方系统、模型或 API 接口输入的任何数据、文字、图纸、工艺配方、操作参数及历史商业文档（统称“客户输入数据”），其全部法定所有权、知识产权及商业机密权益，均不可撤销地完全归属于买方独家所有。
14.2 卖方在此向买方作出严肃且不可撤销的法律承诺：卖方绝不以任何明示或默示的方式，将买方的客户输入数据、模型推理生成的中间数据以及买方用户的反馈数据，用于卖方自身基础模型、垂类模型或任何第三方的算法训练、参数微调、知识蒸馏或产品迭代。
14.3 卖方在完成单次 API 推理或特定业务处理任务后，必须在内存中立即彻底销毁买方的原始输入数据，严禁在卖方服务器、临时缓存或日志文件中持久化存储任何未经买方书面许可的客户数据。
14.4 若卖方违反本条约定，将买方数据用于模型训练或导致买方核心工艺配方发生任何泄露，卖方必须向买方支付相当于本合同总金额 50% 的惩罚性违约金；违约金不足以弥补买方实际经济损失的，卖方必须全额赔偿买方因此遭受的全部直接与间接经济损失，且买方有权依法追究卖方法定代表人及直接责任人的刑事连带责任。

### 第十五条 知识产权归属与免责兜底承诺（IP Indemnification）
15.1 由卖方提供的 AI 模型、智能体系统基于买方输入数据分析推演生成的全部技术成果物、数据分析报告、代码脚本、优化方案及图表（统称“生成成果物”），其全部著作权、专利申请权、商业秘密权益及一切衍生知识产权，均自生成之日起 100% 自动归属于买方所有。
15.2 卖方保证其交付的模型系统、算法底座及训练所使用的数据集完全合法合规，未侵犯任何第三方的著作权、专利权、商标权或商业秘密。
15.3 若任何第三方因买方使用卖方提供的模型或生成成果物而向买方提起任何知识产权侵权指控、仲裁或诉讼，卖方必须自费聘请律师协助买方抗辩，并无条件承担买方因此产生的全部诉讼费、仲裁费、律师费、鉴定费以及生效判决裁定买方承担的全部损害赔偿金。
```
