## 9.2 化工核心原辅材料供应中断应急预案框架（SOP）

### 1. 适用范围与启动条件
本预案适用于因地震、飓风暴雪、地缘政治制裁、主要供应商重大火灾爆炸、重大环保停产或交通大动脉瘫痪，导致企业**关键连续生产原材料、特种催化剂或公用工程介质**发生突发性断供，且厂区可用安全库存已跌破警戒线时的应急指挥处置。

### 2. 应急响应指挥组织架构
```
┌────────────────────────────────────────────────────────────────────────┐
│                   供应链应急保供指挥部（Incident Command）             │
├────────────────────────────────────────────────────────────────────────┤
│ **总指挥**：集团总经理 / 分管生产运营副总裁                             │
│ **副总指挥**：战略采购中心总监、生产调度指挥中心主任                   │
│ **下设专业作战组**：                                                   │
│ · 外部资源紧急寻源调拨组（主责：采购中心品类团队）                     │
│ · 生产工艺负荷微调与配方切换组（主责：工艺技术部/车间）                 │
│ · 现场安全受控与储罐倒运组（主责：安全环保部/仓储物流部）               │
│ · 应急资金专项划拨保障组（主责：财务资金部）                           │
└────────────────────────────────────────────────────────────────────────┘
```

### 4. 应急善后与行动后反思（AAR）
险情解除后 7 个工作日内，指挥部必须召集所有参战部门召开正式的《AAR 应急复盘会》：
1. 详细核算本次应急调拨产生的额外物流溢价与差价损失；
2. 依据合同条款向违约导致断供的原供方发出正式索赔函；
3. 全面审查本次危机暴露出的“单一来源短板”，在 30 天内完成合格二供的开发认证与安全库存水位的永久性向上修正。
