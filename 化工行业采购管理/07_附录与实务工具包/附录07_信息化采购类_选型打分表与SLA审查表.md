## 7.2 信息化服务水平协议（SLA）审查与违约惩戒指标清单

在采购云计算、工业软件运维（AMS）或 SaaS 订阅服务时，必须将服务水平协议（Service Level Agreement, SLA）作为商务合同的核心法律附件。

```
┌────────────────────────────────────────────────────────────────────────┐
│                   企业级信息化系统运维 SLA 服务响应与扣罚标准          │
├──────────────┬────────────────────────────┬──────────────┬─────────────┤
│ 故障严重级别 │ 故障现象与业务影响定义     │ 响应与恢复时限│ 违约扣罚标准│
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **一级故障** │ **核心生产系统全面瘫痪**   │ **30分钟响应** │ 每延期1小时 │
│ (P1-Blocker) │ 导致生产调度中断、DCS数据  │ **2小时内提供**│ 扣罚月度维保│
│              │ 无法采集或全厂财务开票停摆 │ **应急修复**  │ 费的 10%    │
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **二级故障** │ **关键业务模块受阻**       │ **1小时响应**  │ 每延期2小时 │
│ (P2-Critical)│ 某个分厂业务无法过账，或   │ **4小时内提供**│ 扣罚月度维保│
│              │ 质量化验数据无法自动录入   │ **有效解决方案│ 费的 5%     │
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **三级故障** │ **一般非致命系统缺陷**     │ **2小时响应**  │ 纳入季度运维│
│ (P3-Major)   │ 个别报表导出异常、界面报错 │ **24小时内修复│ 考核扣分，超│
│              │ 但业务流程可通过替代手段绕行│ 部署补丁**    │ 期按天扣罚  │
├──────────────┼────────────────────────────┼────────────────────────────┤
│ **四级需求** │ **日常操作咨询与微小调整** │ **4小时响应**  │ 纳入年度用户│
│ (P4-Minor)   │ 用户权限配置、基础字段添加 │ **3个工作日内 │ 满意度评价打│
│              │ 、常规功能操作辅导答疑     │ 闭环归档**    │ 分体系      │
└──────────────┴────────────────────────────┴──────────────┴─────────────┘
```

> **系统可用性保证底线（Availability Guarantee）**：
> 供应商必须在合同中承诺**系统月度服务可用性 $\ge 99.9\%$**（折算每月计划外非计划停机时间累计不得超过 43 分钟）。
> 
> $$\text{月度可用性 } A = \left( 1 - \frac{\text{当月非计划停运总时长 (分钟)}}{30 \times 24 \times 60} \right) \times 100\%$$
> 
> 若月度可用性低于 $99.5\%$，免收当月全额运维服务费；若低于 $99.0\%$，买方有权单方无偿解除合同并没收履约保证金。
