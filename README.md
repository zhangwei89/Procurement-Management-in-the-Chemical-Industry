# 《化工行业采购管理》专著项目工程

> **定位**：国内首部系统打通“传统采购实务 + 装置与工程采购 + 供应链安全合规 + 数字化与人工智能”的化工企业采购管理专业著作与实战案头书。  
> **全书体量**：全书 6 篇、18 章、10 大实务工具包附录，总计 38.2 万字（382,505 字符）。  
> **核心主线**：以需求为起点，以供应资源配置为核心，以质量、成本、交付、安全、合规与保供（QCDSH）为目标构建动态平衡系统。

## 本书四大专业特色与出版亮点

1. **鲜明的流程工业底色**：
   扎根于化工装置连续运行不可中断、易燃易爆有毒有害高危工况、大宗原料价格强周期震荡、微量杂质 ppm 级敏感破坏等化工真实生产运营规律，彻底告别套用离散制造零库存的教条。
2. **严密的数学建模与量化推演**：
   全书包含卡拉杰克象限模型、经济订货批量（EOQ）与正态安全库存（SS）、应有成本（Should-Cost）物料守恒拆解、设备全生命周期成本（LCC）折现、市场集中度 HHI 与 CR4 指数、变异系数 CV、威布尔可靠性磨损模型及财务剔除大盘红利的真实管理硬降本公式。
3. **前瞻系统的数智化与 AI 专篇**：
   涵盖工业控制网（OT）与信息网（IT）隔离、五大核心工业软件选型、大模型私有化与公网 API 经济学平衡点、化工基准测试集（Benchmark 300题）、知识图谱主数据治理、图神经网络反围标串标探针以及采购智能体（AI Agent）半自治落地路径。
4. **12 个行业深度解剖案例与 10 套落地工具包**：
   覆盖大宗原料行情跳水长协失衡、低价中标机封损坏跳车停机、催化剂海外单一来源破局、非标反应器过度设计博弈、急件泛滥治理、工程天价现场签证索赔审计等典型痛点场景；配套表单工具可直接导入企业管理体系使用。
